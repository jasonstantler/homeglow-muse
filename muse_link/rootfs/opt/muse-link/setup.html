Add your Muse SDK token

  1. Get a token at gadgets.muse.ai (Account, then SDK tokens). It starts with mgst_.
  2. Open this add-on's Configuration tab, paste it into Muse SDK token, and click Save.
  3. Restart the add-on, then come back here.

Pair with the Muse app

  1. In the Muse app, turn on Settings → Devices → Developer mode.
  2. Click Start pairing below, then follow the steps that appear.
In the Muse app, add the device named
  1. Tap Settings → Devices → Add Device (the + at the top right).
  2. Pick the device named above.
  3. Muse says it's a community device. Tap Continue.
  4. When it asks for Wi-Fi, pick the network it shows. No password is needed.

Move a pairing here from another machine

Already paired a Linux machine with Muse, like a Raspberry Pi or a virtual machine? Move that pairing here instead of pairing again. Use this if you have an Android phone: the Muse Android app can’t pair over Home Assistant OS’s Bluetooth.

  1. On the paired machine, run this command. It turns Muse off on that machine, because one pairing can only run in one place, and prints a code.
    curl -fsSL https://raw.githubusercontent.com/jasonstantler/homeglow-muse/main/bridge/move-pairing.sh | sudo bash
  2. Copy everything from BEGIN to END, paste it below, and click Move it here.

The code works like a password for your Muse. Don’t share it or post screenshots of it.
